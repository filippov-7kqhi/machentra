# MachEntra

The static storefront for [machentra.shop](https://machentra.shop), served by GitHub Pages
from `main`.

- Business details and payment endpoints: `assets/js/site-config.js`
- Products and prices: `assets/js/catalogue.js` (the Merchant Center feed is `feed.xml`)
- Payments, the Worker and the commands that run them: [`stripe/README.md`](stripe/README.md)
